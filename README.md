# Personal Website

A single, self-contained `index.html` — vanilla HTML & CSS (inline styles, self-hosted fonts), no build step and no dependencies.

## Develop

Open `index.html` directly in a browser, or serve it locally:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy

Any static host works (GitHub Pages, Netlify, Vercel, Cloudflare Pages) — it's a single static file.
